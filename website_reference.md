## 1. Overview

The website is a **static HTML site** auto-generated daily by the GitLab pipeline and pushed to a separate GitHub repository. It serves two purposes:

1. **Landing page** — app download CTA, live WOTD + quiz via GitLab API (JavaScript)
2. **SEO content engine** — hundreds of indexed pages that rank for "[word] meaning in Bengali/Hindi" searches, driving organic installs and eventually AdSense revenue

**Two repos, one site:**

| Repo | Platform | Purpose |
|---|---|---|
| `mahadi07/rtejhs` | GitLab | Pipeline runs here — generates HTML, pushes to GitHub |
| `editorialvocab/editorialvocab.github.io` | GitHub | Website lives here — GitHub Pages serves it |

**Live URL:** `https://editorialvocab.github.io`  
**Docs subfolder:** `https://editorialvocab.github.io/docs/`

## 4. Generated Page Specs

### 4a. WOTD Page (`docs/words/DD-MM-YYYY/{lang}/`)

**File:** `web_generator.generate_wotd_page(lang, wotd_entry, vocab_list, current_date)`

**Content:**
- `<title>` — `{word} meaning in Bengali — 08 June 2026 | Editorial Vocabulary`
- `<meta description>` — word + definition + exam region
- **schema.org** `DefinedTerm` — enables Google Knowledge Graph
- Source badge — `PYQ · BCS 39` (gold) or `Editorial` (grey)
- Word, phonetic, part of speech
- Native language meaning (Bengali/Hindi)
- English definition
- Example sentence
- Synonyms + antonyms chips
- All 10 daily vocabulary words (compact list)
- Cross-link → same-day quiz page
- App download CTA
- Day navigation: ← Yesterday | All Words | Tomorrow →

**SEO target queries:**
- `"PRAGMATIC meaning in Bengali"`
- `"MITIGATE meaning UPSC"`
- `"The Hindu editorial word 08 June 2026"`

---

### 4b. Quiz Page (`docs/quiz/DD-MM-YYYY/{lang}/`)

**File:** `web_generator.generate_quiz_page(lang, quiz_data, current_date)`

**Content:**
- `<title>` — `BCS Quiz — 08 June 2026 | 10 MCQ | Editorial Vocabulary`
- **schema.org** `Quiz` + `Question` + `Answer` — enables Google Quiz rich results
- Q1 gold `PYQ · BCS 39` badge — real past exam question
- Q2–Q10 editorial questions with or without exam cross-reference badge
- Options displayed openly (like real exam paper)
- `<details><summary>Show Answer</summary>` — click to reveal, no JavaScript needed
- Answer shows correct option + source badge
- Cross-link → same-day vocabulary page
- App download CTA
- Day navigation

**Why `<details>` not JavaScript:**
- Works in every browser including old Android WebView
- Google can crawl and index both question AND answer text
- No dependency on JS loading — fast Core Web Vitals

**SEO target queries:**
- `"BCS vocabulary quiz June 2026"`
- `"UPSC English MCQ 08 June 2026"`
- `"editorial vocabulary MCQ today"`

---

### 4c. BCS / UPSC Archive Pages

**Files:** `web_generator.append_to_exam_archive(lang, wotd_entry, current_date)`

Appends to `docs/{tag}-vocabulary/_entries.json` then regenerates the HTML. Only fires when today's source tag contains `BCS`, `PSC`, `UPSC`, `SSC`, or `IAS`.

**Content:** Reverse-chronological list of all exam-tagged words. Each row links to its daily WOTD page. Shows word, native meaning, source badge.

**SEO target queries:**
- `"BCS vocabulary words 2026"`
- `"UPSC previous year vocabulary list"`
- `"Daily Star editorial vocabulary BCS"`

---

### 4d. Words Index (`docs/words/index.html`)

**File:** `web_generator.generate_words_index()`

**Navigation logic:**
```
User clicks "Word Archive" on main site
  ↓
app.js setRegion() saves to localStorage('editorial_region', 'BD'|'IN')
  ↓
/docs/words/index.html JS reads localStorage
  ↓
  BD → redirect to /docs/bcs-vocabulary/
  IN → redirect to /docs/upsc-vocabulary/
  (no pref stored) → redirect to /docs/upsc-vocabulary/ (default)
```

**Noscript fallback:** Two plain buttons shown when JS is disabled (Google Bot sometimes crawls without JS).

## 6. Pipeline Integration

### Call Order in `main.py` Feature 7

```python
# After quiz_pipeline_SEPARATE.main() completes:

# 1. Bengali pages
if wotd_bn_success and wotd_bn_entry.get("word"):
    generate_wotd_page("bn", wotd_bn_entry, vocab_bn, current_date)
    append_to_exam_archive("bn", wotd_bn_entry, current_date)
if quiz_success and quiz_bn.get("questions"):
    generate_quiz_page("bn", quiz_bn, current_date)

# 2. Hindi pages
if wotd_hn_success and wotd_hn_entry.get("word"):
    generate_wotd_page("hn", wotd_hn_entry, vocab_hn, current_date)
    append_to_exam_archive("hn", wotd_hn_entry, current_date)
if quiz_success and quiz_hn.get("questions"):
    generate_quiz_page("hn", quiz_hn, current_date)

# 3. Site-wide — run once regardless of which lang succeeded
ensure_nojekyll()
generate_words_index()
update_sitemap()

# 4. push_docs_to_github_pages() — already in main.py, no change needed
```

### Environment Variables for `push_docs_to_github_pages()`

| Variable | Value | Notes |
|---|---|---|
| `GITHUB_PAGES_REPO` | `https://github.com/editorialvocab/editorialvocab.github.io.git` | Target repo |
| `GITHUB_PAGES_TOKEN` | GitHub PAT | Needs `repo` write scope |
| `GITHUB_PAGES_BRANCH` | `VSCode` | Default |
| `GITHUB_PAGES_TARGET_PATH` | `""` (empty string) | ⚠️ Must be empty so pages go to repo root, not `/docs/docs/` |

**⚠️ Critical:** If `GITHUB_PAGES_TARGET_PATH` is set to `"docs"` the generated files land at `/docs/docs/words/…` which is the wrong URL. Set it to empty string `""`.

## 7. app.js — Required Change

Add one line to `setRegion()` so the words index redirect works:

```javascript
// In app.js — setRegion() function
function setRegion(reg) {
    state.region = reg;
    state.suffix = reg === "BD" ? "EnToBn" : "EnToHn";
    localStorage.setItem('editorial_region', reg);   // ← ADD THIS LINE
    updateBrandUI();
}
```

This saves the user's detected region to `localStorage`. When they navigate to `/docs/words/`, the redirect page reads it and sends BD users to BCS vocabulary, India users to UPSC vocabulary — no extra clicks needed.

## 8. SEO Strategy

### How pages rank

Each daily WOTD page targets the query `"{word} meaning in Bengali/Hindi"`. With 10,000+ daily searches across all BCS/UPSC exam vocabulary words, even 1% click-through at 4 pages/day compounds quickly:

| Months | Pages indexed | Est. monthly impressions | Est. monthly clicks |
|---|---|---|---|
| 1 | ~120 | ~500 | ~50 |
| 3 | ~360 | ~2,000 | ~200 |
| 6 | ~720 | ~8,000 | ~800 |
| 12 | ~1,460 | ~25,000 | ~2,500 |

### Schema.org structured data on every page

| Page type | Schema type | Google feature unlocked |
|---|---|---|
| WOTD page | `DefinedTerm` | Knowledge panel for word definitions |
| Quiz page | `Quiz` + `Question` | Quiz rich results in search |
| Archive page | `ItemList` | Rich list results |
| Landing page | `SoftwareApplication` | App rating stars in Google Play search |

### Internal linking (critical for crawl coverage)

Every generated page links to:
- ← Previous day (WOTD or quiz)
- → Next day
- `docs/words/` index
- BCS or UPSC archive
- Same-day quiz or vocab cross-link

This creates a full crawl mesh so Google discovers every page from any entry point.
